# Mormon Weather

Static preview of the supplied Mormon Weather page. Live forecasts come directly from Open-Meteo; no server or API credentials are required.

## Enable GitHub Pages

In repository Settings → Pages, choose **Deploy from a branch**, select **main** and **/ (root)**, then Save.

The weather page will be at https://cfbrelevant.github.io/utah-sands-manager/weather/ after GitHub finishes deploying.

This preview requests that search engines do not index it. It does not change the Utah Sands production website or domain settings.
