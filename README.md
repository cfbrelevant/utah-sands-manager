# Utah Sands Manager

Private owner-facing mobile app for Utah Sands properties, beginning with 11184 S Haviture Rd, South Jordan, Utah.

> Work in progress. No tenant information, production credentials, or real payment data is stored in this repository. The existing UtahSands resident pages are demonstrations, not live integrations.

The Expo app, event model, and Supabase schema are being developed on a feature branch. Do not use sample amounts or events as actual rental records.
